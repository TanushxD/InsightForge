\# InsightForge



An AI-powered data intelligence platform — upload any dataset and get

automated cleaning, EDA, model training, and eventually a chat interface

to ask questions about your data in plain English.



\## Status

🚧 Week 1 — setting up project foundations.



\## Why this project

Built to learn and demonstrate the full modern data/AI stack: data

engineering, classical ML, deep learning, LLM/RAG integration, agents,

and deployment — one project, growing month by month.
